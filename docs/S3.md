# S3-compatible object storage

Status: **QUALIFIED** against MinIO for the `ObjectStore` contract. Production
Backblaze B2 credentials and a production bucket are not configured yet.

Enable the `rustly-store/s3` feature and construct `S3Store` with an explicit
`S3Config`. The endpoint selects Backblaze B2, MinIO, AWS S3, or another
compatible service without changing callers.

The adapter:

- computes the BLAKE3 CID before upload and chooses the key from that CID;
- stores provenance separately from immutable bytes;
- verifies content and manifest integrity on every read;
- removes corrupt content before reporting an integrity failure;
- bounds object size, each request, retries, and retry delay;
- requires HTTPS except for loopback integration tests; and
- treats credentials as configuration and never logs them.

Use a private bucket and a key restricted to that bucket and deployment prefix.
Do not expose this credential to browsers. Browser uploads require short-lived,
object-specific grants from a trusted service.
